{# The single definition of the favorite control: the details aside includes it and the toggle endpoint answers with it, so both render the same markup. `hx-disable` names the elements htmx disables for the duration of the request and `hx-sync="this:drop"` drops a second click while the first is in flight — together they stop a double-click toggling the favorite twice. `aria-pressed` makes it a toggle button. `outerMorph` keeps the clicked button the same node across the swap, and app.js puts focus back on it once htmx has re-enabled it, so a keyboard user stays where they were. #}
