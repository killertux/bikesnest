## Direction and source
BikesNest is a community-maintained bicycle-parking finder. The bicycle above an open nest-shaped arc suggests a welcoming place to park. This symbol is a proposed new design, not a previously approved asset.

Source repository: `/Users/clemento/Dev/Projects/bikenest`.
Brand references: `design-system/DESIGN.md`, `design-system/colors_and_type.css`, `design-system/preview/brand-assets.html`, and `README.md`.

Existing palette retained as design targets:

- Strong accent: `oklch(45% 0.11 170)`.
- Foreground: `oklch(20% 0.02 240)`; source sRGB reference `#0e171e`.
- Page: `oklch(98% 0.004 240)`.

The image generation prompts target these colors; PNG pixel colors are not guaranteed to be exact token equivalents. The wordmark uses generated geometric sans-serif lettering inspired by the existing Avenir Next direction; it is not live font text.

## Use
Use the horizontal logo on light neutral surfaces in headers and emails. Use the square symbol for compact identity placements. Preserve the full image ratio and surrounding clear space; do not stretch, crop, recolor, add shadows, or place the dark wordmark on dark backgrounds. Prefer at least 160px displayed width for the wordmark and 32px for the icon as starting usage guidance, not a certified minimum.

The icon is a separately generated companion in the same visual direction, not a pixel-exact extraction. Reference-based extraction attempts produced opaque checkerboards, so they were superseded by a standalone transparent generation. There are small differences in bicycle geometry.

These are raster concept assets, not editable vector masters. The HTML and these notes are editable. No SVG, ICO, vector master, or application integration is included. Browser rendering and UI walkthroughs were not performed.
